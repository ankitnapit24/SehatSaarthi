# SehatSaarthi 🏥

SehatSaarthi is an integrated healthcare platform designed to connect patients, ASHA/health workers, doctors, healthcare facilities and government administration through a unified digital ecosystem.

## 🚀 Key Features

- 👨‍⚕️ Doctor and patient management
- 🩺 Digital consultation and appointment support
- 🤖 AI-assisted healthcare support
- 🌐 Multilingual healthcare interface
- 📋 Digital health records
- 💊 Medicine availability and diagnostics support
- 🚑 Ambulance availability
- 🔄 Patient referral tracking
- 👩‍⚕️ ASHA/health-worker dashboard
- 🏛️ Government administration dashboard
- 📱 Responsive web interface
- 🔐 Role-based authentication

## 🛠️ Tech Stack

## 🎯 Objective

The objective of SehatSaarthi is to provide a connected digital healthcare ecosystem that improves coordination between patients, healthcare workers, doctors, laboratories, facilities and government authorities.
